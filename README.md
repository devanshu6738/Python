## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/devanshu6738/Python.git
   cd Python
   ```
2. (Optional) Set up a virtual environment and install common dependencies:
   ```bash
   pip install numpy pandas matplotlib jupyter
   ```
3. Run a script directly:
   ```bash
   python Stack.py
   ```
   Or launch Jupyter for the notebooks:
   ```bash
   jupyter notebook
   ```
